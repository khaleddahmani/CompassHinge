## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CompassHinge.git`
2. `cd CompassHinge`
3. Install in editable mode: `pip install -e .`

## Configuration

CompassHinge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
